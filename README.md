# ZUVIA — Student Portal

A simple educational website for students with:
- Home page
- Study materials section
- Quiz page
- Exam preparation guidance

## Run locally

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open in browser:
   http://localhost:3000

## Publish on Vercel (free)

1. Push this project to GitHub.
2. Go to https://vercel.com
3. Sign in with GitHub.
4. Import the repository.
5. Click Deploy.

## Notes

This is a beginner-friendly website built with Next.js and TypeScript.
